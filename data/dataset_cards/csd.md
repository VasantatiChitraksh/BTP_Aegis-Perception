# Comprehensive Snow Dataset (CSD)

- **ID:** `csd`
- **Role:** general paired synthetic desnowing training/evaluation
- **Contents:** 8,000 train pairs, 2,000 test pairs, and corresponding snow masks
- **Official project:** <https://github.com/weitingchen83/ICCV2021-Single-Image-Desnowing-HDCWNet>
- **Local archive:** `data/archives/csd.rar`
- **SHA-256:** `249876fb519efd54a128377eb910395e8cf3f4cdd461c18aa79598a26efadcbb`
- **Rights:** verify dataset-specific terms; the repository's MIT code license is not assumed to cover data

CSD is the main broad snow-restoration source. It is synthetic and should be
paired with road-oriented SnowCityscapes and real DAWN Snow evaluation rather
than used alone.
