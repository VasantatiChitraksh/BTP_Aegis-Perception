# Dataset cards

These cards record why each automatically collected source exists and what it
cannot prove. Machine-readable download metadata is in `../datasets.yaml`.

| Card | Conditions | Primary role |
|---|---|---|
| `smoke_historical.md` | smoke | Previous-work reproduction |
| `smokebench.md` | smoke | Modern paired generalization |
| `rain100l.md` | rain | Compact standard benchmark |
| `realrain1k.md` | rain | Larger realistic paired data |
| `o_haze.md` | fog | Real paired outdoor evaluation |
| `rtts.md` | fog | Real hazy traffic detection |
| `foggy_driving.md` | fog | Real foggy road imagery/labels |
| `csd.md` | snow | General paired desnowing |
| `snow_cityscapes.md` | snow | Paired road-oriented snow |
| `dawn.md` | rain/fog/snow | Frozen real-road detector evaluation |
