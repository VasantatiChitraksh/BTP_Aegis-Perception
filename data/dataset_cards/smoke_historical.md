# Smoke dataset (ACCV 2022)

- **ID:** `smoke_historical`
- **Role:** reproduce the earlier Attention-Pix2Pix smoke experiment
- **Contents:** 110 train pairs and 12 test pairs (`hazy` / `clean`)
- **Local archive:** `data/archives/smoke_historical.zip`
- **SHA-256:** `92c092a9b688871e5b4cd7b58f6438a37bd5933e75cae578d92064569ce628cf`
- **Official source:** <https://github.com/jinyeying/FogRemoval>
- **Provenance:** official 110-train/12-test Smoke dataset used by the prior semester work
- **Rights:** verify before redistribution; the repository does not state separate data terms

This archive is kept because it exactly reproduces the past work and is the
Smoke test/training set released with *Structure Representation Network and
Uncertainty Feedback Learning for Dense Non-Uniform Fog Removal* (ACCV 2022).
The source is now identified, but the images should still not be committed or
redistributed until the dataset terms are confirmed.
