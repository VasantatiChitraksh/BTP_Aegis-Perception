   Precision                           BF16 autocast for CUDA model execution; reconstruction loss computed from float predictions


 Project tensors use [-1,1]. For Restormer, the trainer multiplies their mean absolute reconstruction error by 0.5, making the training objective
 equivalent to mean L1 on RGB [0,1]. The logged validation L1 uses [-1,1] without this factor, so its magnitude should not be compared
 directly to the logged training L1.


 Evaluation protocol
 Validation and test use native image resolution, batch size 1, and BF16 model execution on CUDA. Input
 padding meets the architecture dimensions and is removed before scoring. Outputs are converted to RGB [0,1]
 and clamped. PSNR uses per-image RGB MSE with a 1e-12 floor, followed by an arithmetic mean across
 images; SSIM uses scikit-image with channel_axis=-1 and data_range=1. These are RGB scores, not Y-channel
 scores.

 All 112 validation images were checked before optimization. Checkpoint selection used validation only. The pretrained and fine-tuned test
 files have matching manifests and evaluation protocols. Numeric metrics are calculated before saving the 8-bit PNG illustrations; figure
 export is not the scoring path.

 Observed: most pairs improve substantially, but a small number remain difficult. In test/107, PSNR rises while
 SSIM falls, so a single metric does not describe every change in structure or appearance. The illustrated result
 also changes brightness/contrast; possible overcorrection is a hypothesis to investigate, not a verified failure
 mechanism.

 Interpretation: fine-tuning adapted pretrained Restormer effectively to this dataset. The improvement does not isolate the effect of L1 versus
 other losses; there was no loss ablation. BF16 completed successfully, but no matched FP32 comparison was run.

 Supported conclusion: a successful single-weather, single-seed Restormer fine-tuning baseline on the recorded RealRain-1k-H split.
 Cross-split near-duplicate scene auditing, seeds 43/44, unseen-dataset evaluation, multi-weather training, detector benefit, FP32/BF16
 comparison, and quantized hardware measurements remain unverified. Single-seed results have no across-seed uncertainty estimate; they
 are not evidence of state-of-the-art performance or submission readiness.
