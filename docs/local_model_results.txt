The finalizer refuses incomplete six-model results. It checks frozen test IDs,
groups, raw metrics, metric protocols, recomputed aggregates, 60-epoch histories,
validation-selected epochs and hashes of evaluated best.pt files. It strictly
loads each model's state dict and checks parameter count. It uses CPU locally;
no model is trained and no DGX queue is changed.

Organization:

  artifacts/models/<model>/best.pt              original selected weights (link)
  artifacts/models/<model>/last.pt              resume state, if downloaded (link)
  artifacts/models/<model>/inference.pt         compact generator-only export
  artifacts/models/<model>/config.json          configuration from selected weights
  artifacts/models/<model>/metrics_test.json    full test results (link)
  artifacts/models/<model>/history.json         complete history (link)
  artifacts/models/<model>/training_run/        original run and periodic checkpoints
  artifacts/models/<model>/SHA256SUMS           integrity record
  artifacts/models/index.json                  six-model catalog
  artifacts/reports/six_models_20261024/        designed PDF, JSON and native examples
  artifacts/restoration/official_v1/comparison.csv   machine-readable metrics

Model folders: attention_pix2pix, restormer, liteweatherformer, transweather,
promptir, ramit. The library uses relative links, not duplicate full checkpoints.
If sharing a linked file, dereference it (cp -L or rsync -L). inference.pt itself

models additionally need artifacts/official_sources and the source lock JSON.
The export is not already quantized or converted to ONNX/TensorRT.

The PDF uses equal-weather/background/stratum metrics, column-wise highlights,
