SCIENTIFIC SCOPE OF THE NEW VISUALS
The 24 gallery panels reuse two labelled scenes with five annotated objects;
weather variants are dependent copies, not independent test scenes. They are
local CPU FP32 controls, not a new mAP benchmark or a device-speed comparison.
The 128 x 128 size describes restoration/resize canvases; detector preprocessing
is the same 640 x 640 letterbox in all three paths.
Restoration histograms give equal weight to images, unlike the balanced headline
benchmark aggregation. Latency histograms normalize each recorded replay run
separately; repeated frames and different displayed x-axis ranges are explicit.
No new inference, model training, hardware run or RAMiT + YOLOv12 result was
introduced. Completed compression studies include rejected candidates.
